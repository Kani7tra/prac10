6. Рекомендательная система (user-based collaborative filtering)

  • Строится матрица «пользователь × товар» со средними оценками.
  • Оценки центрируются относительно средней оценки пользователя.
  • Похожесть пользователей считается косинусной мерой.
  • Оценка товара, который пользователь ещё не оценил, предсказывается по оценкам 10 самых похожих пользователей.

Если у пользователя меньше двух оценок, ему показываются самые популярные товары.

def popular_products(df, n=5, exclude=()): st = df.groupby("product")["rating"].agg(["mean", "count"]) st["score"] = (st["mean"] * st["count"] + 3.5 * 5) / (st["count"] + 5) st = st.drop(index=[p for p in exclude if p in st.index]) return [(p, round(s, 2)) for p, s in st["score"].sort_values(ascending=False).head(n).items()] def recommend_for_user(user_id, n=5, k=10, df=None): df = load_data() if df is None else df matrix = df.pivot_table(index="user_id", columns="product", values="rating", aggfunc="mean") if user_id not in matrix.index or matrix.loc[user_id].notna().sum() < 2: rated = matrix.loc[user_id].dropna().index if user_id in matrix.index else [] return popular_products(df, n, exclude=rated), "популярное" means = matrix.mean(axis=1) centered = matrix.sub(means, axis=0).fillna(0) sim = pd.Series(cosine_similarity(centered)[matrix.index.get_loc(user_id)], index=matrix.index).drop(user_id) neighbors = sim.sort_values(ascending=False).head(k) neighbors = neighbors[neighbors > 0] preds = {} for product in matrix.columns[matrix.loc[user_id].isna()]: r = matrix.loc[neighbors.index, product] mask = r.notna() if mask.sum() == 0: continue w = neighbors[mask] preds[product] = means[user_id] + (w * (r[mask] - means[neighbors.index][mask])).sum() / w.abs().sum() if not preds: return popular_products(df, n, exclude=matrix.loc[user_id].dropna().index), "популярное" preds = sorted(preds.items(), key=lambda x: -x[1])[:n] return [(p, round(float(np.clip(s, 1, 5)), 2)) for p, s in preds], "похожие пользователи" user = "user_005" print(f"Оценки пользователя {user}:") print(df[df["user_id"] == user][["product", "rating"]].to_string(index=False)) recs, method = recommend_for_user(user) print(f"\nРекомендации ({method}):") for p, s in recs: print(f" {p} — прогноз оценки {s}")

Вывод

В ходе работы был разработан ML-продукт для анализа отзывов интернет-магазина косметики. Создан собственный датасет (более 300 отзывов с полями: текст, оценка, товар, дата, пользователь), персональные данные (телефоны, e-mail, имена) скрываются перед сохранением в SQLite. Для классификации тональности сравнены три модели — LogisticRegression, RandomForest и XGBoost — по метрикам Accuracy, Precision, Recall и F1; лучшая модель используется в функции predict_sentiment, которая возвращает тональность и процент уверенности. Реализованы функции топа товаров по доле позитива, частых слов в негативных отзывах, прогноза количества отзывов, а все графики сохранены в student_report.png. Персональные рекомендации строятся методом user-based collaborative filtering, пользователь определяется по ID в cookies. Весь функционал доступен через веб-интерфейс на Flask.
